Manual de Usuario

Documentación técnica y operativa para la plataforma Lycaon Security. Este manual proporciona las directrices necesarias para operar los distintos módulos del sistema operativo.

1. Inicio de Sesión

El módulo de autenticación garantiza el acceso seguro a la plataforma. Para acceder, diríjase a la ruta /login e ingrese sus credenciales asignadas (correo electrónico y contraseña).

En caso de ser un nuevo cliente, puede utilizar la pestaña de registro para crear una cuenta. Esta cuenta tendrá permisos de "Cliente" por defecto hasta que un Administrador asigne un nivel superior.

2. Tienda Pública

La Tienda Pública, accesible a través de /tienda, funciona como la vitrina de los productos actualmente disponibles en el inventario. Los visitantes pueden consultar el catálogo y el estado del stock (Disponible, Poco Stock, Agotado).

Para realizar una compra o gestión de pedidos, es requisito indispensable iniciar sesión en el sistema.

3. Panel de Administración

Una vez autenticado, el usuario es redirigido al Centro de Control. Desde aquí se monitorean las métricas clave de la infraestructura, incluyendo:

  • Métricas de alto nivel: Número de clientes activos, tamaño del catálogo, valoración del inventario y tareas pendientes.
  • Salud del Inventario: Distribución del catálogo por categorías de hardware y estado del stock.
  • Análisis de Ingresos: Gráfica interactiva del flujo de capital.

4. Creación de Productos (Admin)

Los usuarios con rol de Administrador tienen acceso a la sección de Gestión de Inventario. Aquí se administra el catálogo visible en la tienda pública.

A través del formulario integrado, se pueden registrar nuevos componentes en el sistema proporcionando el nombre del equipo, categoría, precio y cantidad de stock inicial. También es posible retirar productos del sistema utilizando la acción de eliminación en la tabla del catálogo actual.

5. Gestión de Usuarios y Permisos

El módulo de Control de Usuarios permite a la administración operar sobre los perfiles del sistema.

  • Nuevo Usuario: Formulario para registrar clientes directamente en la base de datos asignando un rol inicial (Cliente o Administrador).
  • Modificación de Nivel: Utilizando el selector en la tabla, se puede ascender o degradar el rango de cualquier usuario instantáneamente.
  • Baja de Cliente: Eliminación de cuentas para revocar el acceso a la infraestructura.

6. Actualización de Perfil Institucional

Cada cliente puede acceder a la configuración de su cuenta para actualizar sus credenciales visuales.

Mediante el botón "Cambiar Foto", el sistema permite la carga segura de archivos gráficos (JPG, PNG, WebP) que sustituirán el avatar por defecto. Estas actualizaciones se aplican en todo el entorno operativo en tiempo real.
